# Exercício 2 — Sistema de Loja

## Objetivo

Desenvolver um programa em Python para calcular o valor de compras de uma loja e criar testes automatizados utilizando **Pytest**.

## Implementação

Crie um arquivo chamado `loja.py` e implemente as seguintes funções:

```python
calcular_subtotal(precos)
aplicar_cupom(valor, cupom)
calcular_compra(precos, cupom=None)
```

## Regras do Sistema

### `calcular_subtotal(precos)`

A função deverá receber uma lista contendo os preços dos produtos e retornar o valor total da compra.

Considere as seguintes regras:

- O carrinho não pode estar vazio.
- Nenhum produto pode possuir preço igual ou inferior a zero.
- Caso alguma dessas situações ocorra, deverá ser gerado um `ValueError`.

### `aplicar_cupom(valor, cupom)`

A função deverá aplicar um desconto sobre o valor informado.

Os seguintes cupons deverão estar disponíveis:

| Cupom | Desconto |
|---|---:|
| `DESC10` | 10% |
| `DESC20` | 20% |
| `SEMANA30` | 30% |

Caso seja informado um cupom inexistente, deverá ser gerado um `ValueError`.

### `calcular_compra(precos, cupom=None)`

A função deverá:

1. Calcular o subtotal dos produtos.
2. Aplicar o cupom, caso tenha sido informado.
3. Retornar o valor final da compra.

## Testes Automatizados

Crie um segundo arquivo chamado `test_loja.py`.

Utilizando **Pytest**, desenvolva testes para verificar, no mínimo, os seguintes cenários:

1. Compra contendo apenas um produto.
2. Compra contendo vários produtos.
3. Carrinho vazio.
4. Produto com preço igual a zero.
5. Produto com preço negativo.
6. Aplicação do cupom `DESC10`.
7. Aplicação do cupom `DESC20`.
8. Aplicação do cupom `SEMANA30`.
9. Utilização de um cupom inexistente.
10. Compra sem utilização de cupom.
11. Compra com utilização de cupom.

Utilize `pytest.raises` nos testes que verificam situações de erro.

Utilize também `@pytest.mark.parametrize` em pelo menos um conjunto de testes.

## Cobertura de Testes

Ao final, utilize o `pytest-cov` para verificar a cobertura dos testes. Analise o relatório gerado e verifique quais partes da implementação não foram executadas pela suíte de testes.
