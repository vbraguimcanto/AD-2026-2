# Exercício 1 — Sistema de Notas

Desenvolva, em **Python**, um sistema para análise das notas de um aluno.

## Funções a implementar

```python
calcular_media(notas)
verificar_situacao(notas)
maior_nota(notas)
menor_nota(notas)
```

## Regras

- As notas devem estar entre `0` e `10`.
- A lista de notas não pode estar vazia.
- `calcular_media()` deve retornar a média com **duas casas decimais**.
- `verificar_situacao()` deve retornar:
  - Média ≥ 7 → `"Aprovado"`
  - Média ≥ 5 e < 7 → `"Recuperação"`
  - Média < 5 → `"Reprovado"`
- `maior_nota()` deve retornar a maior nota.
- `menor_nota()` deve retornar a menor nota.
- Entradas inválidas devem gerar `ValueError`.

## Testes com Pytest

Crie testes automatizados que cubram:

- Cálculo da média;
- Situação Aprovado;
- Situação Recuperação;
- Situação Reprovado;
- Nota negativa;
- Nota maior que 10;
- Lista vazia;
- Maior e menor nota;
- Limites exatos de média `5.0` e `7.0`.

Utilize pelo menos um teste parametrizado:

```python
@pytest.mark.parametrize(...)
```

E implemente testes de exceção utilizando:

```python
with pytest.raises(ValueError):
    ...
```

## Cobertura de Testes

Ao final, utilize o **pytest-cov** para verificar o percentual de cobertura dos testes. Encaminhe também o **relatório de cobertura gerado** juntamente com a resolução do exercício.

## Objetivo

Praticar funções, listas, validação de entradas, tratamento de exceções, testes automatizados, testes parametrizados e análise de cobertura utilizando **Pytest**.
