# Aplicações Digitais

Repositório destinado aos materiais da disciplina de **Aplicações Digitais**, contendo exemplos, códigos desenvolvidos em aula, exercícios e materiais complementares.

## 📚 Conteúdo

Ao longo da disciplina, este repositório poderá conter:

* Exemplos desenvolvidos durante as aulas;
* Códigos demonstrativos;
* Exercícios práticos;
* Listas de atividades;
* Materiais complementares;
* Projetos e experimentos realizados em sala.

A organização dos diretórios poderá ser atualizada conforme o andamento da disciplina.

## 🎓 Uso acadêmico

Os materiais deste repositório podem ser utilizados para **estudo, ensino, pesquisa e desenvolvimento de outros projetos**.

Você pode:

* Utilizar os códigos;
* Modificar e adaptar os exemplos;
* Compartilhar os materiais;
* Utilizar partes do conteúdo em outros projetos;
* Utilizar os materiais para fins acadêmicos ou comerciais.

Entretanto, ao utilizar ou redistribuir qualquer parte relevante deste repositório, deverá ser fornecido o devido **crédito ao autor e ao repositório original**.
